GreenSprout Community Garden & Café Website

1. Project Overview
This repository contains the frontend implementation for GreenSprout Community Garden & Café, developed for the Web Development assignment.

2. Website Structure
index.html: Homepage with hero banner and mission.
about.html: History and team profiles.
services.html: Plot rentals and workshops.
enquiry.html: Functional volunteer registration form.
contact.html: Contact details and direct message form.
style.css: Responsive stylesheet for all pages.
